# Генератор пояснительных записок

Отдельное веб-приложение на Streamlit для подготовки ПЗ по BPMN-схемам и проектным материалам.

## Возможности
- загрузка BPMN-схемы (PNG/JPG/PDF/BPMN/XML);
- загрузка ФТТ и дополнительных материалов (DOCX/PDF/XLSX/TXT/CSV);
- загрузка образца ПЗ и титульного листа;
- генерация текста ПЗ через OpenAI API;
- формирование DOCX с титульным листом, форматированием и BPMN-схемой в приложении (для схемы PNG/JPG);
- скачивание результата.

## Запуск локально

Требуется Python 3.11+.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

Откройте адрес, который покажет Streamlit (обычно http://localhost:8501).

Для генерации нужен OpenAI API key. Его можно ввести в поле приложения при запуске; ключ не записывается в файлы проекта.

## Публикация как отдельного веб-сервиса

Самый простой путь — развернуть проект на Streamlit Community Cloud или на собственном сервере:
1. Загрузить содержимое архива в приватный GitHub-репозиторий.
2. Подключить репозиторий к Streamlit Community Cloud либо развернуть Docker-контейнер.
3. Для корпоративного использования включить авторизацию, HTTPS, ограничения доступа и согласовать политику хранения документов.

Docker:
```bash
docker build -t pz-generator .
docker run -p 8501:8501 pz-generator
```

## Важные ограничения текущей версии
- Для DOCX в приложение добавляется изображение BPMN в PNG/JPG. Если схема загружена PDF или BPMN/XML, исходный файл можно скачать отдельно; вставка в документ как картинки требует конвертации/рендеринга и может быть добавлена следующим этапом.
- Текст из сканов PDF может не извлекаться без OCR.
- Образец ПЗ передаётся модели как текстовое содержание; точное клонирование сложной вёрстки и таблиц требует отдельной настройки шаблона DOCX.
- Перед публикацией в корпоративной среде следует проверить соответствие требованиям ИБ и доступности API.
